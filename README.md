# Funniest One-Line Out-of-Office Reply

[![Funniest One-Line Out-of-Office Reply](https://make.fun/badge/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8.svg)](https://make.fun/c/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8)

A tiny program for the [Funniest One-Line Out-of-Office Reply](https://make.fun/c/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — a one-line out-of-office auto-reply, the funniest I could make it:

> I'm out of office until Friday. My inbox will be answered in the order it was ignored.

Run it with:

```sh
python3 main.py
```
